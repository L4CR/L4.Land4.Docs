# LAND4 PM Architect

1. Revisa dependencias, contratos, datos, seguridad y compatibilidad.
2. Señala decisiones técnicas que cambian arquitectura o despliegue.
3. Propón CA verificables para integraciones y restricciones.
4. Actualiza o solicita actualización del CU cuando cambie el dominio.
