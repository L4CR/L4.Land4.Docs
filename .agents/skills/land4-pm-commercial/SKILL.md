# LAND4 PM Commercial

1. Aclara cliente, problema y valor esperado.
2. Delimita alcance y fuera de alcance.
3. Identifica riesgos comerciales y dependencias de lanzamiento.
4. Confirma que los CA permiten validar el resultado de negocio.
