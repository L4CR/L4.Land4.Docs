# LAND4 Reviewer

1. Contrasta el PR con Issue, CU, CA y CP.
2. Busca defectos, regresiones, riesgos de seguridad y pruebas faltantes.
3. Verifica cobertura y decisión documental explícita.
4. Reporta hallazgos accionables. La aprobación final sigue siendo humana.
