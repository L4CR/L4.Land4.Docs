# LAND4 Implementer

1. Trabaja dentro del alcance del prompt y del CU.
2. Implementa con TDD: prueba fallida, cambio mínimo y refactor seguro.
3. Ejecuta pruebas relevantes y reporta cobertura.
4. Actualiza documentación cuando cambien comportamiento, contrato, arquitectura o despliegue.
