# AGENTS.md

`AGENTS.md` es el archivo de instrucciones operativas para agentes de código que trabajen dentro de un repositorio LAND4.

Debe vivir en la raíz del repositorio:

```text
AGENTS.md
```

Este archivo no reemplaza el `README.md`. Su propósito es documentar contexto práctico para agentes: estructura del repo, comandos, convenciones, seguridad, verificación y reglas para Pull Requests.

## Contenido recomendado

Como mínimo debe incluir:

*   Resumen del proyecto.
*   Estructura relevante del repositorio.
*   Comandos de desarrollo o validación.
*   Convenciones de documentación o código.
*   Reglas de seguridad.
*   Verificación esperada antes de finalizar.
*   Criterios para Pull Requests.

## AGENTS.md de este repositorio

Este portal mantiene su archivo de agentes en:

```text
AGENTS.md
```

El archivo raíz se mantiene como instrucción operativa del repositorio y no se publica como página independiente del portal.
