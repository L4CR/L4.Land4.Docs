# Casos de Uso

Los casos de uso son contratos vivos del dominio versionados junto al código. Cada contrato vive en:

```text
docs-repo/req/<caso-de-uso>/CONTRACT.md
```

## Contratos publicados

*   **[CU-001 - Registro de comercio](../registro-comercio/):** Ejemplo de contrato con tablas procesables.

## Convención

*   El CU describe el dominio, no el incremento de entrega.
*   El CU no mantiene una lista de US relacionadas.
*   La US referencia uno o más CU desde la plataforma de backlog.
*   Usa la **[Plantilla de Contrato de Caso de Uso](../CASO_USO_TEMPLATE.html)** al crear un contrato.
